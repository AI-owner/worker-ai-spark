# Roadmap

> **Chinese version:** [阅读中文版](ROADMAP.md)

> This document describes possible stages for the Worker AI Spark Project. All stages are **proposals and possibilities**, not commitments to a timetable, funding, computing resources, or staffing. Progress depends on sustained work by real participants.

---

## Phase 0: Initial project release (repository foundations complete)

Goal: establish an initial repository content version for public review on GitHub. “Complete” refers to repository foundations, not formal review approval or a published GitHub Release. See [current progress](docs/project-status.en.md) for version and participation status.

- Complete the three core documents: manifesto, basic principles, and first evaluation questions.
- Establish the repository structure.
- Establish contribution and governance rules.
- Create the first machine-readable evaluation dataset (`benchmarks/first-batch.zh-CN.jsonl`).
- Create basic automated validation (`scripts/validate_benchmarks.py`).
- Reserve directories for model evaluations and a knowledge base.

---

## Phase 1: Public review (general feedback open; formal review in preparation)

Goal: involve more workers, developers, and researchers in examining and revising the project.

General feedback can be submitted through Discussions, existing Issues, or the official mailbox. Formal review requires the [opening conditions](docs/review/README.en.md#i-current-status) to be met and a round notice to be published. See [participation information](docs/project-status.en.md#how-to-participate-now).

- Establish review and feedback mechanisms.
- Invite workers, frontline engineers, researchers, and developers to review.
- Revise the Basic Principles for Workers' AI.
- Revise the first batch of working-class standpoint evaluation questions.
- Record disputes, minority opinions, and perspectives from different theoretical backgrounds.
- Develop an initial transparent framework for contributions, revisions, and governance.

---

## Phase 2: Multi-model evaluation

Goal: use the first question set to evaluate several existing models and publish methods, rather than only a simple leaderboard.

- Select existing models from more than one possible provider.
- Preserve original responses, prompts, and execution methods.
- Use multiple scorers.
- Publish preliminary evaluation reports.
- Show dimension distributions, major disqualifying issues, and real risks, not just rankings.

---

## Phase 3: Labor knowledge base

Goal: organize public knowledge about labor for use by AI and the public.

- Organize public, lawfully available material on labor history, labor law, occupational safety, workers' literature, factory systems, platform work, and related topics.
- Record sources and scope of applicability.
- Establish privacy and copyright practices.
- **Do not upload unauthorized material** or appropriate workers' experience without compensation in the name of building Workers' AI.

---

## Phase 4: Local open-source prototype

Goal: explore a limited but transparent, controllable open-source system that others can maintain and build upon.

- Choose an open-source model that can run locally.
- Connect the labor knowledge base.
- Incorporate the Basic Principles for Workers' AI.
- Evaluate results with the question set.
- Do not start from worship of model size or computing power.

---

## Phase 5: Shared governance

Goal: move gradually from an individual initiative to maintenance by multiple parties.

- Develop a stable group of actual maintainers.
- Establish procedures for changing core documents.
- Establish contribution records and dispute resolution.
- Reduce dependence on a single maintainer.
- Prevent technical contributions from automatically becoming permanent power.

---

## Notes

The roadmap may change through discussion and practice. Changes to stages should explain their reasons, preserve historical versions, and remain open to public discussion. The project's value depends on understanding workers and helping them gain knowledge, dignity, and a voice in social decisions, not on owning the largest model.
