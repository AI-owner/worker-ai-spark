## 记录原则

- 项目尊重并记录真实劳动；
- 贡献形式多样：代码、理论、写作、翻译、案例、审阅、纠错、社区维护与组织，也包括联系劳动者、了解他们对 AI 的期望、项目宣传、后续建设工作和被采纳的合理意见；
- 不能只承认容易被软件统计的劳动，也不能把基础性、照护性和协调性工作变成不可见劳动；
- 贡献值只用于项目内的荣誉公示，是“为工人阶级工作”的荣誉凭证，本身不带来任何实际利益；
- 公开摘要不包含劳动者的身份、联系方式或未经同意的交流内容。

## 如何被记录

- 通过 Pull Request 合并的贡献，由维护者按本框架登记；
- 不会使用 Git 的贡献者，可通过维护者公布的渠道提交，由维护者代为登记并注明；
- 志愿者实际完成的工作，以及被采纳的合理意见，由项目维护方登记，确定贡献值并简要说明依据，详见 [贡献值说明](../CONTRIBUTORS.md#三贡献值与回馈)；
- 是否公开身份由贡献者决定（真实姓名 / GitHub 用户名 / 化名 / 匿名）。
