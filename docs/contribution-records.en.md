> **Chinese version:** [阅读中文版](contribution-records.md)

> This file records individual contributions and each assigned contribution value. Cumulative values are published in the [honor roll](../CONTRIBUTORS.en.md#4-contribution-honor-roll). Add detailed records as real contributions occur.

---

## Recording principles

- Respect and record real labor.
- Contributions include code, theory, writing, translation, cases, review, corrections, community maintenance and organization, worker contact, understanding workers' hopes for AI, outreach, future development work, and reasonable suggestions that are adopted.
- Do not recognize only work that software can easily count, or make foundational, caring, and coordinating work invisible.
- Contribution values are solely honorary recognition within the project of “working for the working class”; they carry no material benefits.
- Public summaries exclude workers' identities, contact details, and conversations not authorized for publication.

## How contributions are recorded

- Maintainers register contributions merged through Pull Requests using this framework.
- Contributors who do not use Git can submit through announced channels; maintainers register and credit their work.
- Maintainers record volunteers' actual work and adopted reasonable suggestions, assign values, and briefly explain the basis; see [contribution values](../CONTRIBUTORS.en.md#3-contribution-values-and-giving-back).
- Contributors choose whether to use a real name, GitHub username, pseudonym, or anonymity.
