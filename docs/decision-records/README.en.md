# Decision Records

> **Chinese version:** [阅读中文版](README.md)

> This directory records important decisions about project direction and rules, especially changes to core documents, licensing, and governance.

Create a separate DR record when review feedback materially changes core direction, licensing, or governance, and link it to the relevant Pull Request or commit. Do not create a project-level DR for every ordinary comment.

---

## Purpose

- Help later participants understand why a decision was made.
- Preserve historical versions and differing views.
- Prevent silent overwriting or decisions existing only in individuals' memories.

---

## Suggested format

```text
ID: DR-001
Date: YYYY-MM-DD
Topic:
Background:
Discussion and differing views:
Decision:
Reasons:
Subsequent effects:
Related review decisions:
Related Pull Request / commit:
Does this need further discussion?:
```

## Notes

- Revisability prevents a standpoint from becoming dogma detached from reality; it does not mean abandoning it.
